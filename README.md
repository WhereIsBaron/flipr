# FLIPR: Flip Profit Tracker

A Torn userscript that logs what you paid for bazaar / item-market purchases (via your own Torn API key) and warns you before you list them below a real profit, accounting for Torn's item-market sales tax.

## Install

Install via a userscript manager (Tampermonkey / Violentmonkey) from the GreasyFork listing, or grab [`flipr.user.js`](flipr.user.js) directly.
